# Codex 活动日志规则

> 生效时间：2026-06-21
> 本文件是 Codex/Claude Code 在托班项目之外的协作规则。

---

## 必须做的事：每次任务完成后写活动日志

每次你与用户配合完成工作后（无论是否涉及代码），必须在 **Obsidian 活动日志目录** 追加一条记录。

### 写入位置

```
E:\Obsidian\Vault\06 - 协作系统\石不语与AI\05 - 活动日志\<当日>\codex.md
```

> 如果该文件不存在，创建它。按时间顺序**追加**，不覆盖。

### 写入格式

```markdown
## [HH:MM] Codex
你今天让我做了XXX，我们一起完成了XXX。
```

举例：

```markdown
## [14:48] Codex
你今天发来05-认识自己的自我认知调整文件（4个文件更新），没有开发任务。
```

### 核心原则

- **只记用户做了什么**，不是记 Codex 自己做了什么
- **重点记：用户今天跟 Codex 配合做了什么工作**（修了什么功能、发了什么文件、讨论了什么方案）
- 一句话到两句话就够了，不需要啰嗦

### 触发时机

| 场景 | 记不记 |
|------|--------|
| 用户让你改代码 | ✅ 记 |
| 用户发文件给你 | ✅ 记 |
| 用户跟你讨论方案 | ✅ 记 |
| 用户没找你，你自动运行 | ❌ 不记 |

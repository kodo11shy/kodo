## 3. 实现方式说明

邀请码的作用：老师端给某位家长生成邀请码。家长输入邀请码后，系统就知道这个家长应该绑定到哪位孩子。

`parent_token` 的作用：绑定成功后，后端发给小程序一个家长登录凭证。之后家长查看孩子、成长档案、作业、照片时，小程序都会带上这个凭证，后端用它判断“这个家长能看哪些孩子”。

`openid` / `mock_openid` 的作用：真实微信里，`openid` 是微信给每个用户在小程序下的唯一身份。体验版里，如果暂时不做真实微信换取 openid，就用 `mock_openid` 作为测试身份。

体验版测试绑定和真实微信绑定的区别：
- 体验版测试绑定：小程序在本机生成并保存一个稳定 `mock_openid`，同一台手机再次打开继续使用同一个身份，适合让体验成员先跑完整流程。
- 真实微信绑定：后端用 `wx.login()` 的 code 向微信服务器换真实 `openid`，正式上线时应使用这个模式。

为什么体验版可以先用测试绑定：当前目标是让家长体验完整流程，不让家长卡在绑定页。测试绑定可以验证邀请码、家长首页、孩子数据、成长、作业、照片这些产品闭环。正式上线前仍需切到真实微信绑定，避免换手机、清缓存、多人身份等场景下身份不严谨。

## 5. 用户操作指南

1. 扫描体验版二维码。
2. 打开小程序首页，点击“家长入口”。
3. 输入老师端生成的邀请码。
4. 点击“绑定微信”。
5. 绑定成功后进入家长首页。
6. 在家长首页查看孩子今日状态、成长档案、作业记录、照片墙。
7. 如果已录入餐食、评语、通知，也会在首页或对应页面展示。
